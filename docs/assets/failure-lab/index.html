Replay and reduce
Download a trace and execute its ordered actions with the same engine. Operation bytes are checked during replay. Minimization keeps the same failing invariant and reports whether the schedule is minimal under single-action deletion.


npm run failure-lab
npm run failure-lab -- --sim-only
npm run failure-lab -- replay path/to/scenario.trace.json
npm run failure-lab -- minimize path/to/failing.trace.json


The historical replica-alias demonstration deliberately assigns one identity to two replicas. It is isolated to this lab. The fixed replay changes that allocation policy and retains the same ordered actions. Live operating-system and database scheduling are not reproduced by this simulated trace.
